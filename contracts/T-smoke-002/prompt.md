# T-smoke-002 通道冒烟 · WorkBuddy（只读，禁止改文件）

你在 pair-crew 班组里扮演「实现者」，本次是**只读冒烟**，用来确认工作区绑定。

## 必须完成

1. 报告当前项目根的绝对路径（用工具读到的真实路径）。
2. 列出 `skills/pair-crew/templates/` 下所有文件名。
3. 打开 `docs/multi-agent-pair-plan.md`，用不超过 10 行概括其中的：
   - 角色划分（有哪些角色）
   - 测试分层（含 UI 测试两类）

## 约束（SCOPE）

- **禁止**修改、创建、删除任何文件
- **禁止**安装依赖或运行构建
- 若找不到上述路径，说明你实际打开的工作区是什么，不要猜

## 输出格式

```
PROJECT_PATH: <绝对路径>
TEMPLATES:
  - ...
SUMMARY:
  ...
```
